# Farmland Accounting
Description:\
This program enables you to keep track of animals on the farm,
monitoring their numbers and sizes. It allows you to easily add
new animals, pens, or even entire farms.

Techniques:\
The program implements the Composite pattern, making it highly extensible. 
It also demonstrates the fundamentals of object-oriented programming in C++ 
and the SOLID principles.

Launch requirements:\
- CMake
- compiler with support C++17
